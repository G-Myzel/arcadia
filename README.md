# Arcadia — Fliperama

Projeto de estudo em Python para praticar funções, listas, dicionários, módulos e validação de entradas.

## Como executar

Requer Python 3.10 ou mais recente:

```bash
python main.py
```

É possível cadastrar máquinas e seus jogos, ligar ou desligar cada máquina, registrar partidas, consultar o ranking de um jogo e ver o resumo do dia. Uma máquina ligada só aceita partidas do jogo cadastrado nela. As informações ficam em memória e são apagadas ao encerrar o programa.
